# Alba Network Demo

A small standalone desktop UI prototype with its own Alba branding. This is a visual demo only; it does not create VPN tunnels, connect to real networks, or impersonate Radmin VPN.

## Run
Requires Java 21 or newer.

```powershell
java -jar AlbaNetworkDemo.jar
```

## Keyboard shortcut
Press **Ctrl + Q** to show the placeholder for the second-app integration planned for a later stage.

The network names and participants are sample data.
